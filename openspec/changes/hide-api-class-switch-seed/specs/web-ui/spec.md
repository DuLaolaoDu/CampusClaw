# web-ui Specification

## Purpose

提供服务端渲染（SSR）的 Web 页面，作为浏览器用户的唯一交互入口：登录、仪表盘（材料列表/上传/预览/下载）、教师班级切换。页面交互全部通过表单提交 + 服务端重定向完成，浏览器端不依赖任何 /api 端点。

## ADDED Requirements

### Requirement: 页面通过表单完成登录与登出
系统 SHALL 提供登录页面（含 username/password 表单）与登出表单入口，凭据校验成功后建立会话并重定向到仪表盘；登出后清除会话并回到登录页。

#### Scenario: 登录页表单提交成功跳转仪表盘
- **WHEN** 用户在登录页提交正确凭据
- **THEN** 浏览器被重定向到仪表盘页面，且页面显示当前用户名、角色、生效班级

#### Scenario: 登录失败回到登录页并提示
- **WHEN** 用户在登录页提交错误凭据
- **THEN** 浏览器回到登录页并显示统一的"用户名或密码错误"提示，不区分账号不存在与密码错误

#### Scenario: 已登录用户访问登录页被重定向
- **WHEN** 已登录用户直接访问登录页 URL
- **THEN** 浏览器被重定向到仪表盘，不重复显示登录表单

### Requirement: 仪表盘服务端渲染材料列表
系统 SHALL 在服务端渲染仪表盘：按生效班级返回材料列表（标题、上传者、班级、时间），文件材料显示原文件名、大小与下载链接，文本与文件材料均可展开预览提取正文。

#### Scenario: 列表数据由服务端注入
- **WHEN** 已登录用户请求仪表盘页面
- **THEN** 返回的 HTML 中 SHALL 已包含本班（生效班级）材料数据，无需浏览器再发起任何数据请求

#### Scenario: 文件材料展示下载链接与预览
- **WHEN** 列表中存在文件材料且当前用户有下载权限
- **THEN** 该条目 SHALL 展示原文件名与格式化大小，并提供指向用户侧下载路由的链接与提取正文预览

#### Scenario: 学生视角无上传表单
- **WHEN** 学生用户请求仪表盘页面
- **THEN** 页面 SHALL 不渲染上传表单区域，但完整渲染列表、下载链接与预览

### Requirement: 教师可切换生效班级
系统 SHALL 在仪表盘为教师渲染班级切换控件（下拉框仅列出其任教的班级）；选择后经表单提交更新服务端会话中的生效班级并刷新页面。

#### Scenario: 教师看到任教班级下拉框
- **WHEN** 教师用户请求仪表盘页面且其任教多于一个班级
- **THEN** 页面 SHALL 渲染班级切换控件，选项恰好为该教师任教的班级集合，当前生效班级处于选中态

#### Scenario: 学生不渲染班级切换控件
- **WHEN** 学生用户请求仪表盘页面
- **THEN** 页面 SHALL 不渲染任何班级切换控件

#### Scenario: 切换后列表立即反映新班级
- **WHEN** 教师在切换控件中选择另一任教班级并提交
- **THEN** 浏览器重定向回仪表盘，页面显示新生效班级的标签与该班材料列表

### Requirement: 上传通过页面表单提交
系统 SHALL 在仪表盘为教师渲染上传表单：纯文本（标题+正文）与文件（.txt/.md/.pdf，≤10MB）共用一个 multipart 表单，提交到用户侧页面路由；校验失败重新渲染表单并显示服务端错误文案。

#### Scenario: 文本方式上传成功回列表
- **WHEN** 教师提交仅含标题与正文的表单
- **THEN** 服务端创建材料（正文入库）并重定向回仪表盘，新记录出现在列表顶部

#### Scenario: 附带文件上传成功并自动提取
- **WHEN** 教师提交含附件（.txt/.md/.pdf 且 ≤10MB）的表单
- **THEN** 服务端保存文件、提取文本入 content 并重定向回仪表盘，新条目显示文件名与大小

#### Scenario: 校验失败重新渲染并提示
- **WHEN** 教师提交缺少标题、类型不在白名单或超过 10MB 的表单
- **THEN** 浏览器回到仪表盘且 SHALL 显示服务端返回的错误文案；数据库与磁盘不产生该次提交的任何写入

### Requirement: 浏览器端零 /api 依赖
系统 SHALL 保证页面在浏览器中的全部交互（登录、登出、列表展示、上传、下载、班级切换）通过页面路由完成，页面资源中不包含对 /api 的 fetch/XHR 调用。

#### Scenario: 页面源码无 /api 调用
- **WHEN** 检查仪表盘与登录页返回的 HTML 及其引用的脚本
- **THEN** 不得存在任何指向 /api 的前端请求代码；页面功能在 /api 被边缘代理屏蔽时仍完整可用

#### Scenario: 未登录访问受保护页面重定向登录
- **WHEN** 未登录用户直接访问仪表盘 URL
- **THEN** 浏览器被重定向到登录页而非收到 401 JSON
