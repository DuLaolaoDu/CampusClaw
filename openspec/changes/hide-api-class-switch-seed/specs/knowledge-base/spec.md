# knowledge-base Specification

## ADDED Requirements

### Requirement: 用户侧材料下载路由
系统 SHALL 提供面向浏览器用户的材料下载路由（区别于内部 API）：已认证用户下载其生效班级内的文件材料时，获得与原文件字节一致、以原文件名作为下载名的响应；跨班、不存在或纯文本材料返回 404，未认证重定向到登录页。

#### Scenario: 本班文件材料下载成功
- **WHEN** 用户请求其生效班级内某文件材料的用户侧下载路由
- **THEN** 响应 SHALL 为 200，字节数与上传时一致，下载名等于原始文件名

#### Scenario: 跨班下载不可达
- **WHEN** 用户请求 class_id 不等于其生效班级的材料下载路由
- **THEN** 系统返回 404，不泄露材料存在性

#### Scenario: 纯文本材料无可下载文件
- **WHEN** 用户对纯文本（无附件）材料请求下载路由
- **THEN** 系统返回 404（正文通过页面预览呈现，而非文件下载）

#### Scenario: 未登录下载重定向登录页
- **WHEN** 未认证用户请求下载路由
- **THEN** 系统重定向到登录页（页面路由语义），而不是返回 401 JSON

## MODIFIED Requirements

### Requirement: 教师可以上传教学材料
系统 SHALL 提供材料上传能力，浏览器用户的入口为页面表单路由（multipart：标题 + 可选正文 + 可选文件附件 .txt/.md/.pdf ≤10MB）；内部 API 上传端点保留供程序化调用但不对用户暴露。两条路径的校验与持久化语义一致，校验失败不产生任何数据库或磁盘写入。

#### Scenario: 上传纯文本材料成功
- **WHEN** 已认证的 teacher 角色提交包含 title 和 content 的文本上传
- **THEN** 系统持久化成功并使新记录可被标识（页面重定向回列表展示该记录；内部 API 路径返回 201 与 id、title、class_id、owner_id、created_at 字段）

#### Scenario: 上传时缺少 title 或 content 被拒绝
- **WHEN** 教师上传时缺少 title、缺少 content（且无附件）、或两者皆缺
- **THEN** 系统拒绝该次提交（页面重新渲染提示必填项；内部 API 返回 400），数据库不产生任何写入

#### Scenario: 上传空字符串内容被拒绝
- **WHEN** 教师上传时 title="" 或 content=""（空字符串或仅空白）且无附件
- **THEN** 系统拒绝该次提交，不得写入任何数据

#### Scenario: 页面表单上传文本材料成功
- **WHEN** 已认证的教师在页面表单提交 title 与 content（无附件）
- **THEN** 系统持久化材料并重定向回仪表盘，新记录立即出现在其生效班级列表顶部

#### Scenario: 页面表单上传文件材料成功并自动提取
- **WHEN** 教师在页面表单提交 title 与 .txt/.md/.pdf 附件（≤10MB）
- **THEN** 系统保存文件、将提取文本写入 content，重定向后新条目展示原文件名、大小与预览

#### Scenario: 页面表单校验失败重新渲染
- **WHEN** 教师提交缺少标题、附件类型越界（如 .docx、伪装 pdf）或超过 10MB 的表单
- **THEN** 页面重新渲染并显示服务端错误文案，数据库与磁盘无该次提交的任何写入

#### Scenario: 内部 API 上传语义保持
- **WHEN** 程序化客户端（容器内部网络）调用内部 API 上传端点
- **THEN** 校验、班级归属、响应字段语义 SHALL 与页面路径一致（该端点外部不可达）
